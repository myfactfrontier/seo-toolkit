## 5. Outline

```
H1  — includes the primary keyword naturally
  Intro — direct answer in the first 2 sentences, then context

H2  — [question or subtopic]
  Answer-first paragraph (quotable, self-contained, 40-60 words)
  Supporting detail
  H3 — [specific case]

H2  — [question or subtopic]
  ...

H2  — FAQ
  3-5 questions, each answered in one short paragraph
```

## 7. Schema

- [ ] Article / Product / LocalBusiness *(pick one — matches the page's job)*
- [ ] FAQPage — if there's a genuine FAQ section
- [ ] BreadcrumbList — matches the visible breadcrumb
- [ ] HowTo — only if the content is genuinely procedural

## 8. Assets

- [ ] Original image / diagram / chart — with descriptive alt text
- [ ] Data table — extractable, not an image of a table
- [ ] Screenshot or proof where a claim needs it

## 9. AEO / GEO checklist

- [ ] Every H2 opens with a self-contained answer
- [ ] At least one extractable definition or data block
- [ ] Author byline with credentials
- [ ] Publish and update dates visible
- [ ] Claims sourced, with outbound links to primary sources
